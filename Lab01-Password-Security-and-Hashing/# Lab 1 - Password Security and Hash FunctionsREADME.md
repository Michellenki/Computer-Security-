
# Lab 1 - Password Security and Hash Functions

## Objective

To understand password hashing, compare MD5, SHA-1 and SHA-256, observe the Avalanche Effect and explain password salting.


## Tools

- Python 3
- hashlib library
- Ubuntu/Windows



## Concepts Covered

- Plaintext
- Hash
- Ciphertext
- Password Storage
- SHA-256
- MD5
- SHA-1
- Salting
- Avalanche Effect



## Procedure

1. Create a sample password.
2. Generate an MD5 hash.
3. Generate a SHA-1 hash.
4. Generate a SHA-256 hash.
5. Change one character.
6. Generate new hashes.
7. Compare outputs.
8. Observe Avalanche Effect.
