
# Computer Security Labs

Practical cybersecurity laboratory exercises completed as part of **CCS 4103 – Computer Security**.

## Technologies

- Python
- Ubuntu Linux
- Wireshark
- Nmap
- UFW Firewall

## Topics Covered

- Password Security and Hash Functions
- AES Symmetric Encryption
- RSA Public-Key Cryptography
- Digital Signatures
- Diffie–Hellman Key Exchange
- Packet Capture using Wireshark
- Linux File Permissions
- Web Security Basics
- Firewall Configuration
- Vulnerability Assessment using Nmap
- Digital Forensics
- Security Logging and System Auditing

## Learning Outcomes

- Understand password hashing and salting
- Implement symmetric and asymmetric encryption
- Analyze network traffic
- Configure Linux firewalls
- Perform vulnerability assessments
- Verify file integrity
- Analyze security logs
